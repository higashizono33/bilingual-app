# app/

フロントエンド（子供向け録画UI・保護者ダッシュボード）を配置するディレクトリです。

現時点ではまだ実装前（雛形のみ）です。想定する機能は [`../docs/requirements.md`](../docs/requirements.md) の5章（機能要件）を参照してください。

操作イメージのモックは [`../docs/prototype.html`](../docs/prototype.html) にあります（データ保存なしの単一HTMLプロトタイプ）。

## 想定機能（要件定義より抜粋）

- 毎日の「今日は何をした？」への日本語→英語の動画回答UI（`getUserMedia` によるアプリ内録画）
- 録画した動画をS3へPresigned URLで直接アップロード
- 保護者向けダッシュボード（英語で話せた時間・語彙数などの推移グラフ、動画再生、子供プロフィール管理）
- 保護者モード認証（Amazon Cognito 等）
