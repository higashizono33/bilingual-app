毎日「日本語→英語」の順で動画回答 → S3保存(mp4標準) → 英語のみAI分析 → ダッシュボード表示。requirements.md 8章に対応。

📱 子供が動画で回答（日本語→英語の順）
iPad/iPhoneのアプリ内カメラで ja.mp4 → en.mp4 の順に撮影
↓
🔐 Presigned URL でアップロード
バックエンド非経由・転送コストなし
↓
☁️ AWS Cloud（家族専用アカウント）
🪣 Amazon S3（Private）
SSE-S3暗号化（無料） / childId/date/lang.mp4（webmはフォールバック） / 子供の顔写真も保存
🇯🇵 ja.mp4
↓
💾 保存のみ
AI分析対象外（参考記録・比較用）
🇺🇸 en.mp4
↓
⚡ Lambda（トリガー）
S3イベント直起動・言語フィルタ
↓
🗣️ Amazon Transcribe
非同期ジョブ / 月60分は無料枠内目安 / 失敗時は自動リトライ（指数バックオフ）
↓
⚡ Lambda（指標算出）
ルールベース：発話時間・語数・ユニーク語彙(レンマ)・新出語彙・WPM・TTR・ポーズ分析
（単語信頼度スコアはMVP対象外）
↓
🗄️ DynamoDB（オンデマンド）
分析結果・累積語彙リストを子供別に保存 / status(uploaded→transcribing→analyzed/failed)
┄┄▶
🤖 Amazon Bedrock
将来オプション：文法・CEFR相当の定性評価
（コスト優先のため初期MVPでは見送り）
🌐 S3 静的ホスティング（ダッシュボード）
CloudFrontなし（家族限定アクセスのため不要）
↑ 認証
🔑 Amazon Cognito
家族共有ログイン1アカウント（個別アカウントなし）・無料枠内
🐙 GitHub（Public リポジトリ）
CDK/Lambda/ダッシュボードのコードを管理（動画・分析データは含まない）
↓
⚙️ GitHub Actions
PR時: Lint/簡易テスト / mainマージ時: 自動デプロイ
↓ OIDC連携（長期アクセスキー不使用）
🧱 AWS CDK（TypeScript）でデプロイ
